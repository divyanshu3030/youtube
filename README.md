# 🎥 YouTube Clone

A responsive YouTube Clone built using **React**, **Vite**, and **React Router**. This project recreates the core YouTube interface with a modern UI, search functionality, a collapsible sidebar, and responsive video cards.

---

## ✨ Features

- 🔍 Real-time video search
- 📺 Responsive video grid
- 🎨 Modern YouTube-inspired UI
- 📱 Fully responsive layout
- 📂 Sidebar navigation
- ➕ Create button with upload menu
- 🔔 Notification icon
- 👤 User profile section
- ⚡ Fast development using Vite
- 🧩 Component-based architecture

---

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript (ES6+)
- CSS3
- React Router DOM
- React Icons

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/youtube-clone.git
```

### 2. Navigate to the project

```bash
cd youtube-clone
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
